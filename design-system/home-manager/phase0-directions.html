A · Ledger

The Stripe-leaning option. Cool slate neutrals, an indigo accent, hairlines instead of boxes. Inter with tabular figures; JetBrains Mono for references and rule versions. Small radii (4 / 6 / 10). The main area is white and the sidebar sits on the canvas.

B · Household book

Calm and editorial. Source Serif 4 for page titles and headline figures, IBM Plex Sans and Mono for the rest. Breakdowns read like a tax worksheet: numbered lines, a double rule above the total. Warm paper neutrals, deep teal accent, near-square corners (2 / 3 / 6). Tables use dotted row rules and no header fill.

C · Family

Friendlier, for family members who aren't finance-minded. Plus Jakarta Sans throughout, a cobalt accent, softer radii (6 / 10 / 14), and tinted surfaces where the others use rules. Category shares show as bars, from percentages the server sends. Rows are 40px.

From Pro Max, and what changed

  • Kept: Swiss minimalism, low motion, a dashboard density.
  • Swapped Fira Code / Fira Sans for Inter, because Fira Code headings read like a code editor.
  • Dropped the green accent, because green means money in, and the dark-only default. The scroll-reveal animation is gone too.

From Pro Max, and what changed

  • Kept: a serif + sans editorial pairing, a calm palette and minimal motion.
  • Rejected Playfair Display (too luxury-fashion) and Caveat / Quicksand (handwriting).
  • The worksheet styling comes from the app's own tax worksheets, not from Pro Max.

From Pro Max, and what changed

  • Kept: Plus Jakarta Sans and a trust-blue accent.
  • Dropped glassmorphism (blur and translucency hurt contrast and break "no shadows in the page flow").
  • Dropped the orange call-to-action color, because orange reads as a warning here.

The same in all three

  • Money out is − in the text color, money in is + in green, and transfers are muted with ⇄. Red only appears for errors and past due.
  • Every figure opens its breakdown: formula, lines with running totals, "Sums to ✓", inputs with unconfirmed ones first, and the rule card.
  • Status always has an icon and text. Verified rows stay quiet.
  • All fonts are open-licensed (OFL) and get self-hosted in Phase 1. This preview loads them from Google Fonts only for convenience.
